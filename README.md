## Developer Guide

Requires [uv](https://docs.astral.sh/uv/#installation).

1. Create your Python 3.14 virtual environment, e.g. `uv venv --python 3.14`
2. Activate with `source .venv/bin/activate`
3. Install dependencies with `uv sync --dev`
4. Run with `python -m assistant.main`
